# Python Algorithms – ETE288 \& ETE389

A collection of Python solutions and algorithm implementations developed as part of the coursework for **ETE288** and **ETE389**.

## 

## Topics covered

|Area|Algorithms and problem types|Concepts demonstrated|
|-|-|-|
|Graph algorithms|Dijkstra, Prim's minimum spanning tree, Dinic, Edmonds–Karp, bipartite matching|Graph representations, priority queues, residual networks and augmenting paths|
|Grid problems|Minimum-cost paths, cave navigation, gold collection|Breadth-first search, Dijkstra and path reconstruction|
|Dynamic programming|0/1 knapsack, currency exchange|State transitions and optimization over subproblems|
|Search|Grid traversal, wildcard matching, integer-vector search|BFS, queues, visited states and pattern matching|
|Optimization|Scheduling, divisor enumeration|Greedy strategies, balancing and number theory|
|Simulation|Firefly obstacle calculations|Counting, cumulative sums and array processing|
